# Healthcare Data Preprocessing and Cleaning

## Project Overview

This project focuses on handling missing values and outliers in a healthcare dataset. The dataset contains patient health records including age, gender, BMI, blood pressure, cholesterol, glucose levels, and disease risk.

The project demonstrates different missing value imputation techniques and outlier detection methods to prepare a clean dataset for machine learning applications.

## Dataset Features

- patient_id
- age
- gender
- region
- bmi
- blood_pressure
- cholesterol
- glucose
- disease_risk

## Missing Value Techniques

- Missing Value Analysis
- Mean Imputation
- Median Imputation
- Most Frequent Imputation
- Missing Indicator
- Random Sample Imputation
- KNN Imputer
- MICE (Multiple Imputation by Chained Equations)

## Outlier Detection Techniques

- Z-Score Method
- IQR Method
- Percentile Method

## Outlier Treatment

- Winsorization

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- SciPy

## Outcomes

- Cleaned healthcare dataset
- Reduced missing values
- Treated extreme outliers
- Machine-learning-ready data
